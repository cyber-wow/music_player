# Music_player
Music player - это статический сайт-визитка для онлайн-плеера.
## Структура проекта
* `index.html` — главная страница сайта.
* `style.css` — файл стилей для оформления страницы.
* `images/` — изображения и иконки для оформления меню и интерфейса.
* `font/` — необходимые стили текста.
## Функциональность
* Интерактивные элементы, такие как кнопки,ссылки,якоря.
* Стилизация с использованием шрифтов, картинок.
## Как запустить проект
1. Скачайте или клонируйте репозиторий.
2. Установите шрифты из `font/`
3. Откройте `index.html` в браузере.
